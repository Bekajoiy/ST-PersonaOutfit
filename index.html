Wardrobe features

Three views

Switch between List, Compact and Gallery. Drag to reorder in any view and keep a separate order for each persona.

Adjustable Gallery

Choose 2–6 columns and square thumbnails from 65 to 140 px. The panel expands to fit and scrolls on narrow screens.

Thumbnail framing

Pan and zoom a square crop for the outfit picker. The floating image window keeps the full image.

Dynamic Chat Avatar

Optionally show the equipped outfit beside chat messages attributed to the active persona. The original avatar file stays intact.

Equip in one click

Fill the [outfit: ] placeholder in the persona description. The active outfit is highlighted.

Floating previews

Open the full image and outfit description in separate windows. Move, resize or disable each window independently.

Install Persona Outfits

  1. Open Extensions → Install Extension in SillyTavern.
  2. Paste the repository URL shown here, then confirm and reload.
  3. Click the shirt button or run /outfits to open your wardrobe.

Repository URL

https://github.com/Bekajoiy/ST-PersonaOutfit

Already installed? Update it in Extensions → Manage Extensions.

Equip your first outfit

  1. Put [outfit: ] anywhere in your persona description.
  2. Choose New outfit, add a name, description and optional image, then save.
  3. Click the outfit to equip it. The placeholder now contains its description.
