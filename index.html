Features

Small panel, complete wardrobe.

01

Per-persona lists

Switching persona switches the outfit list. The header shows whose wardrobe you are looking at.

02

Click to wear

Replaces [outfit: ] in the persona description and leaves the rest of the text untouched.

03

Two floating windows

The outfit image and description open in separate windows. Drag, resize and close them independently.

04

Drag to reorder

Grab the grip on the left of a row and drop it wherever you want. The order is saved per persona.

05

Local images

Images are downscaled and stored in SillyTavern's settings. No upload service and no telemetry.

06

Theme-aware

The floating panels follow SillyTavern's theme, and the shirt button can be dragged out of the way.

Installation

Two ways to install.

01

From Git (recommended)

Open Extensions → Install Extension in SillyTavern, paste https://github.com/Bekajoiy/ST-PersonaOutfit, and confirm.

02

Or copy the folder

Put the project folder in data/<your-user>/extensions/. For the default user: data/default-user/extensions/.

03

Reload and open

Reload SillyTavern, then click the shirt button in the corner or run /outfits.

Usage

Write once, wear in a click.

  1. Add a placeholder. Put [outfit: ] anywhere in the persona description.
  2. Create outfits. Give each one a name, a description and an optional image.
  3. Click to wear. The placeholder becomes [outfit: your description]; the rest of the persona is untouched.
  4. Arrange the list. Drag the grip on the left of a row. The order is saved per persona.

Good to know

Local, quiet, and easy to undo.

  • Images are downscaled and stored inside SillyTavern's settings.json. There is no upload service and no telemetry.
  • Deleting an outfit removes its image and thumbnail. New outfits stay as drafts until you click Save.
  • Deleting a persona also removes its outfit list and images; other personas are untouched.
  • The image and description windows are independent; each can be toggled in Extensions → Persona Outfits.
  • External image URLs are loaded by your browser, so that host will see the request.
